# DbSchemaCompare (Binaries)

Kompilierte Windows-Binaries (Releases) zu [DbSchemaCompare](https://www.powershelldba.de/dbcompare/) — enthält nur Build-Output, keinen Quellcode.

Download, entpacken, `DbSchemaCompare.exe` starten. .NET Framework 4.8 (in Windows 10 2004+/Windows 11 enthalten), kein Installer nötig.
